# Security Policy

Whisper Phone handles private communications, so responsible disclosure is
especially important.

## Supported versions

Security fixes are applied to the latest code on `main`. Until stable release
channels are published, older snapshots are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature on the repository's **Security** tab.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Please allow a reasonable amount of time to investigate
and coordinate a fix before public disclosure.

## Scope and expectations

This project has not received an independent security audit. Its use of
well-known cryptographic primitives does not by itself guarantee that the
application or protocol is secure. Review the documented limitations before
using it for sensitive or high-risk communications.
